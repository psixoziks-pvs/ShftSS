# EmoSharp — Эмоциональный шрифт с острыми краями

**EmoSharp** — это концептуальный системный шрифт, разработанный в стиле "эмо" с характерными острыми краями и выразительными формами. Шрифт поддерживает полную локализацию под все языки мира и все существующие символы Unicode.

## Особенности

- 🖤 **Стиль "эмо"**: Острые углы, вытянутые формы, драматичные контрасты
- 🌍 **Полная локализация**: Поддержка всех языков мира
- 🔤 **Универсальность**: Все символы Unicode (более 149 000 символов)
- 💻 **Системная установка**: Может быть установлен как системный шрифт
- ✨ **Уникальный дизайн**: Не существует в реальности — создан специально для этого репозитория

## Структура проекта

```
Shfts/
├── README.md              # Этот файл
├── EmoSharp_FontSpec.md   # Спецификация дизайна шрифта
├── install.sh             # Скрипт установки для Linux/macOS
├── install.bat            # Скрипт установки для Windows
└── fonts/                 # Директория для файлов шрифтов (концепт)
    └── EmoSharp-Regular.ufo  # Формат UFO (Unified Font Object)
```

## Установка

### Linux/macOS
```bash
chmod +x install.sh
./install.sh
```

### Windows
Запустите `install.bat` от имени администратора.

## Характеристики шрифта

| Параметр | Значение |
|----------|----------|
| Название | EmoSharp |
| Стиль | Emo / Gothic / Alternative |
| Кегль | 8–72 pt |
| Вес | Regular, Bold, Black |
| Поддержка Unicode | Полная (все planes) |
| Лицензия | Conceptual / Free for personal use |

## Примечание

Этот шрифт является **концептуальным проектом**. Для реальной генерации файлов шрифтов (.ttf, .otf) требуется специализированное ПО (FontForge, Glyphs, RoboFont). Данный репозиторий содержит полную спецификацию и инструкции для создания шрифта.
