# Спецификация шрифта EmoSharp

## Основная информация

- **Название шрифта**: EmoSharp
- **Версия**: 1.0.0 Conceptual
- **Автор**: Shfts Project
- **Категория**: Display / Alternative / Emo Style

## Дизайн-концепция

### Визуальный стиль
Шрифт выполнен в эстетике "эмо" с следующими характеристиками:

1. **Острые края**: Все символы имеют выраженные острые углы вместо скруглений
2. **Вытянутые пропорции**: Вертикальная ось доминирует, создавая драматичный вид
3. **Контрастность**: Сильный контраст между толстыми и тонкими штрихами
4. **Асимметрия**: Некоторые элементы намеренно асимметричны для выразительности
5. **"Слёзы" и "капли"**: Декоративные элементы в виде капель на некоторых символах

### Цветовая палитра (для веб-версии)
- Основной: #1a1a1a (глубокий чёрный)
- Акцент: #ff0066 (ярко-розовый)
- Дополнительный: #6600cc (фиолетовый)

## Технические характеристики

### Метрики шрифта
```
UPM (Units Per Em): 1000
Ascender: 900
Descender: -250
Cap Height: 700
x-Height: 500
Line Gap: 100
```

### Поддержка Unicode

Шрифт поддерживает все основные блоки Unicode:

#### Основные латинские символы
- Basic Latin (U+0000–U+007F)
- Latin-1 Supplement (U+0080–U+00FF)
- Latin Extended-A/B/C/D (U+0100–U+ABFF)

#### Кириллица
- Cyrillic (U+0400–U+04FF)
- Cyrillic Supplement (U+0500–U+052F)
- Cyrillic Extended-A/B (U+2DE0–U+A6FF)

#### Азиатские языки
- CJK Unified Ideographs (U+4E00–U+9FFF)
- Hiragana (U+3040–U+309F)
- Katakana (U+30A0–U+30FF)
- Hangul Syllables (U+AC00–U+D7AF)

#### Ближневосточные языки
- Arabic (U+0600–U+06FF)
- Hebrew (U+0590–U+05FF)
- Thai (U+0E00–U+0E7F)

#### Индийские языки
- Devanagari (U+0900–U+097F)
- Bengali (U+0980–U+09FF)
- Tamil (U+0B80–U+0BFF)
- И другие...

#### Символы и знаки
- Mathematical Operators (U+2200–U+22FF)
- Currency Symbols (U+20A0–U+20CF)
- Arrows (U+2190–U+21FF)
- Geometric Shapes (U+25A0–U+25FF)
- Emoticons (U+1F600–U+1F64F)
- Emoji (U+1F300–U+1F9FF)

#### Полный охват
- Всего поддерживается: **149,813 символов** (Unicode 15.1)
- Количество глифов: ~200,000 (с лигатурами и альтернативами)

## Начертания

Шрифт доступен в следующих начертаниях:

1. **EmoSharp Regular** (weight: 400)
2. **EmoSharp Bold** (weight: 700)
3. **EmoSharp Black** (weight: 900)
4. **EmoSharp Italic** (weight: 400, style: italic)

## Форматы файлов

Шрифт распространяется в следующих форматах:

- `.ttf` (TrueType Font) — для максимальной совместимости
- `.otf` (OpenType Font) — для продвинутых функций
- `.woff2` (Web Open Font Format) — для веба
- `.ufo` (Unified Font Object) — исходный формат для редактирования
